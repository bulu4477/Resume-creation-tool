# Resume Builder - 在线简历编辑器

一个免费、无需登录的在线简历编辑器，支持多种模板，实时预览，一键导出PDF。

## 特性

- ✨ **无需登录** - 所有数据保存在本地浏览器
- 🎨 **多种模板** - 现代、经典、极简、专业四种风格
- 👁️ **实时预览** - 编辑时即时看到效果
- 📄 **PDF导出** - 一键导出高质量PDF
- 🔄 **自动保存** - 数据自动保存到本地存储
- 📱 **响应式设计** - 支持各种屏幕尺寸

## 技术栈

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Zustand (状态管理)
- html2canvas + jsPDF (PDF导出)

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 使用说明

1. 选择喜欢的模板风格
2. 填写个人信息
3. 添加工作经历、教育背景
4. 添加技能和项目经历
5. 点击"导出PDF"按钮下载简历

## 模板说明

- **现代风格**: 简洁现代，适合科技行业
- **经典风格**: 传统正式，适合传统行业
- **极简风格**: 极简主义，突出内容
- **专业风格**: 商务风格，适合管理岗位

## 数据存储

所有数据自动保存在浏览器的 localStorage 中，无需担心数据丢失。你也可以：
- 点击"加载示例"查看示例简历
- 点击"重置"清空所有数据
- 点击"清空"彻底删除本地存储
